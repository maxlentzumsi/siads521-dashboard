# siads521-dashboard
Repository for SIADS 521 dashboard (assignment 3)


This project explores EPA UCMR 5 drinking water data collected during 2023–2025 through an interactive dashboard built with Plotly and Streamlit. Users can compare contaminant occurrence, examine individual measurements, and explore public water system findings by state using bar charts, scatter plots, a Sankey diagram, and a choropleth map. A Jupyter notebook documents data preparation and visualization development, while prepared CSV files power the publicly hosted dashboard. The analysis distinguishes minimum reporting levels from health-based reference concentrations and supports exploration rather than regulatory compliance assessment.
